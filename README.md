# ⚽ ScoutAI — FIFA World Cup 2026 AI Predictor

> AI-powered match prediction app for all 48 World Cup 2026 teams.
> Built with React + Vite + DeepSeek R1 via Groq API.

🌐 **Live at:**[(https://scoutai-world-cup-pr-lrcv.bolt.host)]

## What it does
- Predicts match outcomes using DeepSeek R1 reasoning AI
- Real team news pulled via GNews API before each prediction
- Live World Cup scores via ESPN API (updates every 60s)
- Win probability, predicted scoreline, tactical breakdown,
  player duel analysis and form guide
- PWA — installable on mobile like a native app
- Freemium model — 1 free Pro prediction, then ₹150/month

## Tech Stack
React 18 · Vite · Groq API (DeepSeek R1) · 
GNews API · ESPN Scoreboard API · PWA · Capacitor

## Run locally
1. Clone this repo
2. `npm install`
3. `npm run dev`
4. Open Settings tab → paste your Groq API key
   (free at console.groq.com)
